## 💡 Туох движогай taas-checkmate?

**taas-checkmate** — диэн Rust уонна GPU (CUDA) тылыгар суруллубут мэйии клеткаларын (нейроннары) симуляциялыыр олус түргэн Yлэлэтэр движок.

 бэлиэ: манна нейроннар просто матрица чыыһылалара буолбатахтар — кинилэр **тыыннаахтар**: уоту (заряды) мунньуналлар, спайк (чаҕылҕан/импульс) таһаараллар, химическай рецептордарынан кэпсэтэллэр уонна үөрэнэллэр.

---

## 🔬 Мэйии иһэ хайдах үлэлиирэ (Судургутук быһаарыы)

### 1. 🫗 Нейрон — "уулаах ыстакаан"
Аллара өттүгэр кыра уулаах ыстакааны хараххар ойуулаа.
- Ыстакаан иһигэр атын нейроннартан куруук уу (электрическэй ток `I`) кутуллар.
- Уу бытааннык таах каапылыыр буоллаҕына, үүтүнэн ааһан барар — ыстакаан кураанах хаалар.
- Үөһэттэн уу күүскэ кутулыннаҕына — уу таһыма түргэнник үөһэ тахсар! Таһым малайгар тиийдэҕинэ (**порог $V_{thresh}$**), ыстакаан эргиччи эргийэр — **"СПАЙК" (чаҕылҕан/импульс)** тахсар!
- Импульс кэнниттэн ыстакаан кураанахтыйар (**сброс $V_{reset}$**) уонна аҕыйах кэмҥэ сынньанар (**рефрактерный период**).

---

### 2. 🌿 Дендриттар — "Мутуктаах уу турабата"
Сигнал нейрон киинэрэ дароба тиийбэт. Нейрон элбэх мутуктаах — **дендриттаах**.
- Каждого мутук — уһун уу турабата.
- Сигнал устун иһэн тураба куолаһыттан сылтаан мөлтүүр (**сопротивление $R_a$**).
- **taas-checkmate** иһигэр дендриттар **активнайдар**: тураба иһигэр кыра автоматическай насостар ($Na^+$, $K^+$, $Ca^{2+}$) тураллар. Сигнал күүһүрдэҕинэ насостар өссө күүскэ аһан таһаараллар — **дендритнай спайк** буолар!

---

### 3. 🔑 Синапстар уонна Рецептордар — "Күлүүстэр уонна Замоктар"
Биир нейрон спайк таһаардаҕына, атын нейроҥҥа химическай хааппыла ыытар. Атын нейрон тэлгэһэтигэр араас рецептор-замоктар тураллар:
- **AMPA**: Түргэн замок. Түргэнник аһыллар — уу нейрон иһигэр кутуллар.
- **NMDA**: Өйдөөх замок. Иһигэр магний пробкалаах ($Mg^{2+}$). Аһылларыгар нейрон бэйэтэ аҕыйахтик уоттаах буолуохтаах — өйдөбүл уонна үөрэх олоҕо.
- **GABA**: Тохтотор (тормозной) замок. Уу кутарын оннугар алларараа үүтү аһар — нейрону соруйан сойутар!

---

### 4. ⚡ SIMD уонна GPU — "Параллельнай конвейердар"
10 000 000 ыстакааны биир-биир аахтахха — көмпүүтэр өр симиэ этэ.
- **SIMD (AVX2 / AVX-512)**: 8 эбэтэр 16 ыстакааны **биир процессор тагыгар бириэмэҕэ** ааҕабыт!
- **GPU (CUDA)**: Видеокарта тыһыынчанан ядердарыгар муха эбэтэр кыыл мэйиитин бириэмэҕэ ааҕабыт.

---

### 5. 🎓 Үөрэх — "Хебб быраабылата уонна Дофамин"
Мэйии хайдах үөрэнэрий?
- **STDP**: Нейрон А нейрон Б иннинэ спайктаатаҕына — кинилэр сибээстэрэ күүһүрэр ("Бииргэ чаҕылыс гыммыт нейроннар — сибээстэһэллэр").
- **Дофамин (3-Factor Plasticity)**: Секунда кэнниттэн эмоциональнай наҕараада (дофамин) кэллэҕинэ — ити суоллар куруук күүстээх сибээскэ кубулуйаллар!

## 🏗 Проект структурота

```
taas_checkmate/
├── crates/
│   ├── pillars/        ← Единый канон: api + zoo + kernels (SIMD)
│   ├── pillars-macros/ ← Модель макростарын (#[dual_neuron])
│   ├── pillars-cuda/   ← GPU: NVRTC-модели + gpu-микроядра (GpuContext)
│   ├── pillars-connectome/ ← FlyWire коннектома + Brain/sim_*
│   ├── t3/             ← Мэйии ритмнарын движога (Курамото)
│   ├── train/          ← Обучение (RL Actor-Critic, E-Prop)
│   └── taas-format/    ← .taas формат
```

## 🚀 Саҕалааһын

```bash
# Клонирование уонна сборка
git clone https://github.com/anomalyco/taas-checkmate.git
cd taas-checkmate
cargo build --no-default-features

# Тесттары ыытыы (154/154 тест)
cargo test --all-features
```

### Python иһигэр туттуу
```python
import taas_checkmate as tc

# 1000 нейрону биир шагынан ааҕыы
v, u, spikes = tc.step_izhikevich(v, u, I, dt=0.5)

# Муха коннектомун симуляциялыахха
brain = tc.BrainSimulator(n_neurons=130000, model="lif")
spike_buffer = brain.step_batch(dt_ms=0.5, n_steps=100)
```
