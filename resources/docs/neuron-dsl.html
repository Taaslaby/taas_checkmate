01Движок реального времени

Как устроен pillars: пять слоёв и один конвейер компиляции

Движок разделён на пять слоёв со строгой односторонней зависимостью api → zoo → ops → core; батч-микроядра kernels живут рядом с ops и никогда не кормят zoo. Каждый слой — одна ответственность, код не пересекает больше одной границы за раз.

api/
Оркестратор: NeuralPopulation, Network, графы. Safe Rust, без сырых указателей.
zoo/
25+ готовых моделей. Строятся из ops + core, никогда не зовут kernels.
ops/
Био-кирпичики: ohmic, gate, spike, пластичность — чистые функции над S.
kernels/
Батч-микроядра: плоские срезы на вход, SIMD-цикл + скалярный хвост.
core/
SIMD-движок: трейт SimdLane → f32x8 | f32. Здесь generic становится инструкцией.

Мономорфизация вместо интерпретации

Модель пишется один раз — в терминах трейта SimdLane (generic над S). При компиляции Rust подставляет и f32x8 (8 нейронов за такт), и f32 (скаляр, любой CPU). Весь SIMD-код порождается на этапе компиляции. 

ваша модель:   let spike = v.cmp_ge(v_thresh);
                    ↓
        SimdLane trait (generic over S: SimdLane)
                    ↓
   ┌───────────────────┼───────────────────┐
   │  S = f32x8        │  S = f32          │
   │  _mm256_cmp_ps    │  ucomiss + setae  │
   │  (AVX2 / NEON)    │  (скаляр)         │
   └───────────────────┴───────────────────┘

Один шаг популяции

  • Память — Struct-of-Arrays с выравниванием до 8: колонки v, u, refr… по capacity = n.div_ceil(8)*8.
  • n ≤ 8 — скалярный путь; n > 8 — SIMD-чанки по 8 + скалярный «хвост» (паритет хвоста покрыт тестами побитово).
  • Входной ток клампится до ±100 (I_SYN_CLAMP_RANGE): защита от переполнения экспонент, нефизичных частот и NaN.
  • Опциональные шины i_pre / i_post — для STDP и пластичности.

02Свой нейрон на DSL

Минимальная модель — 20 строк, полный SIMD-пайплайн — бесплатно

Единственный способ написать модель — структура с атрибутами #[state] и #[param] + реализация трейта ComputeNeuron. Макрос #[derive(NeuronModel)] генерирует весь мост к движку. 

use pillars::prelude::*;
use pillars::NeuronModel;   // derive-макрос реэкспортируется корневым крейтом
use pillars::core::compute::{ComputeNeuron, StepContext};
use pillars::core::lane::SimdLane;

#[derive(NeuronModel)]
pub struct MyLIF {
    #[state] pub v: f32,        // мембранный потенциал, мВ
    #[state] pub refr: f32,     // таймер рефрактерности, мс

    #[param] pub dt: f32,       // шаг интегрирования, мс
    #[param] pub inv_tau_m: f32, // 1/τ — движок не любит делений
    #[param] pub v_rest: f32,
    #[param] pub v_thresh: f32,
    #[param] pub v_reset: f32,
    #[param] pub tau_ref: f32,
}

impl ComputeNeuron for MyLIF {
    type State<S: SimdLane> = MyLIFState<S>;
    type Params<S: SimdLane> = MyLIFParams<S>;

    #[inline(always)]
    fn step<S: SimdLane>(
        state: &mut MyLIFState<S>,
        params: &MyLIFParams<S>,
        ctx: &mut StepContext<S>,
    ) {
        let zero = S::zero();
        let is_refr = state.refr.cmp_gt(zero);

        // Forward Euler: без делений, чистая FMA-арифметика
        let dv = (params.v_rest - state.v + ctx.i_syn) * params.inv_tau_m * ctx.dt();
        let v_new = state.v + dv;

        // Спайк только вне рефрактерности (нет back-to-back)
        let spike = is_refr.cond().then(zero)
                           .else_(v_new.cmp_ge(params.v_thresh));
        ctx.emit_spike(spike);              // ← спайк уходит в шину

        let v_final = spike.cond().then(params.v_reset).else_(v_new);
        state.v = is_refr.cond().then(state.v).else_(v_final);

        let refr_dec = state.refr - ctx.dt();
        state.refr = spike.cond().then(params.tau_ref).else_(refr_dec).max(zero);
    }
}
Правила DSL Поле обязано быть #[state] или #[param] — ничего другого быть не может. Нужно минимум по одному полю каждого типа. Для моделей, которые не стреляют спайками (синапсы, глия, мышцы), вешайте #[no_spike] на структуру — раннер пропустит запись спайк-маски.

Что это даёт

  • Типизированный доступ: только state.v, params.v_thresh — никаких магических номеров колонок.
  • Zero-cost: мост — одна инлайновая функция «именованные поля ⇄ SoA-память», без рантайм-диспетчеризации.
  • Один исходник — компилируется в AVX2, NEON и скаляр одновременно.
  • Генерация: MyLIFState<S>, MyLIFParams<S>, энумы индексов и реализация Model — см. раздел 05.

03ComputeNeuron — сердце шага

Типизированный трейт, StepContext и идиома «cond → then → else»

Всё, что нужно знать о контракте шага:

pub trait ComputeNeuron: crate::zoo::Model {
    type State<S: SimdLane>;    // генерирует макрос
    type Params<S: SimdLane>;   // генерирует макрос

    fn step<S: SimdLane>(
        state: &mut Self::State<S>,
        params: &Self::Params<S>,
        ctx: &mut StepContext<S>,
    );
}

// StepContext — что видит модель на каждом шаге:
pub struct StepContext<S: SimdLane> {
    pub i_syn: S,      // постсинаптический ток (сумма по входам)
    pub i_pre: S,      // пресинаптическая шина (для STDP)
    pub i_post: S,     // постсинаптическая шина (для STDP)
    pub dt: f32,       // шаг в мс (скаляр, broadcast через .dt())
    spike_mask: S,     // сюда пишет emit_spike()
}

Идиомы, которые вы будете использовать

  • cond.cond().then(a).else_(b) — «маска»: если cond истинно, берём a, иначе b. Без ветвлений.
  • ctx.emit_spike(mask) — единственный способ сообщить о спайке.
  • S::zero() / S::one() / S::splat(v) — константы и broadcast.
  • Сравнения: cmp_ge / cmp_gt / cmp_lt / cmp_le, max / min / clamp01, exp / ln / sin / cos.

Пример с воротными кинетиками и омическими токами — так выглядит «живой» нейрон (HAAP, упрощённо): 

fn step<S: SimdLane>(
    state: &mut HAAPState<S>,
    params: &HAAPParams<S>,
    ctx: &mut StepContext<S>,
) {
    use pillars::ops::*;   // био-кирпичи — чистые функции

    let i_leak = params.g_l * (state.v - params.e_l);            // I = g·(V − E)
    let i_m    = params.g_m * state.u * (state.v - params.e_k);  // M-ток
    let i_h    = params.g_h * state.h * (state.v - params.e_h);  // h-ток

    let dv = (ctx.i_syn - (i_leak + i_m + i_h)) * params.inv_cm;
    let v_new = state.v + dv * ctx.dt();

    // u_∞ = 1 / (1 + exp(−k·(V − V_half))) — сигмоида, аргумент клампится ±50
    let u_arg = (-params.k_u * (v_new - params.v_half_u))
        .max(S::splat(-50.0)).min(S::splat(50.0));
    let u_inf = S::one() / (S::one() + u_arg.exp());
    let u_new = (state.u + ctx.dt() * (u_inf - state.u) * params.inv_tau_u).clamp01();

    let spike = v_new.cmp_ge(params.v_thresh);
    ctx.emit_spike(spike);

    state.v = spike.cond().then(params.v_reset).else_(v_new);
    state.u = spike.cond().then(u_new + params.delta_u).else_(u_new).clamp01();
}

04Био-кирпичи: модуль ops

Переиспользуемые примитивы — чистые функции над S, без памяти и состояния

Каждый оп — это fn op<S: SimdLane>(…S…) → S. Один код работает и в SIMD, и в скаляре. Модель собирается из них как из LEGO.

Пример из «внутренностей» — спайк-детекция как чистые функции:

// fire-and-reset: спайк если v ≥ v_thresh, сброс в v_reset
pub fn fire_reset<S: SimdLane>(v: S, v_thresh: S, v_reset: S) -> (S, S) {
    let spike = v.cmp_ge(v_thresh);
    let v_new = spike.cond().then(v_reset).else_(v);
    (v_new, spike)
}

// edge-triggered: только нарастающий фронт — защита от «залипания» над порогом
pub fn edge_spike<S: SimdLane>(is_above: S, was_below: S) -> (S, S) {
    let spike = is_above.and(was_below.cmp_gt(S::zero()));
    let was_below_next = is_above.cond().then(S::zero()).else_(S::one());
    (spike, was_below_next)
}

05Что генерирует #[derive(NeuronModel)]

Из 20 строк модели — полный типизированный API за бесплатно

Для структуры MyLIF макрос порождает:

  • MyLIFState<S> / MyLIFParams<S> — типизированные структуры (поле = лейн S).
  • MyLIFModelParamIdx / MyLIFModelStateIdx — энумы-индексы: вариант = номер колонки, никаких магических чисел.
  • Реализацию Model — мост: загрузил типизированные state/params из SoA → вызвал ComputeNeuron::step → записал обратно + спайк-маску.
  • Константы PARAM_COLS, STATE_COLS и HAS_SPIKE (ложь при #[no_spike]).

Заполнение параметров — теперь по имени, а не по номеру колонки:

let mut pop = NeuralPopulation::<MyLIF>::new(8);

// Новый путь — сгенерированный энум:
pop.fill_param(MyLIFModelParamIdx::InvTauM.into(), 0.1);
pop.fill_param(MyLIFModelParamIdx::VThresh.into(), -54.0);
pop.fill_state(MyLIFModelStateIdx::V.into(), -70.0);

// Legacy-путь — по номеру колонки (порядок = порядку полей):
pop.fill_param(0, 0.5);   // dt
pop.fill_param(1, 0.1);   // inv_tau_m

07Быстрый путь: run_neuron

Для абсолютного максимума пропускной способности — сырые указатели, никаких обёрток

Если NeuralPopulation нужен для разработки и отладки, то run_neuron::<M> — для «боя»: прямой SIMD-цикл по колонкам, без валидаций и аллокаций. Тот же движок, тот же код модели — только ближе к металлу. 

// n должно быть кратно 8 для максимальной скорости
unsafe {
    run_neuron::<LIFModel>(
        v.as_mut_ptr(),        // state 0: v
        refr.as_mut_ptr(),     // state 1: refr
        ptr::null_mut(),       // state 2..5: не используются
        ptr::null_mut(),
        ptr::null_mut(),
        ptr::null_mut(),
        I.as_ptr(),            // входной ток
        spikes.as_mut_ptr(),   // спайки (0/1)
        params.as_ptr(),       // [n×N_PARAMS], колонки
        n,
    );
}
Когда что использовать NeuralPopulation — безопасный путь по умолчанию. run_neuron — если нужна абсолютная скорость (например, realtime-дрозофила на 130K нейронов). Есть также run_neuron_ext и run_neuron_par (Rayon-параллель по чанкам).

11Конвенции движка

Правила, которые держат численную стабильность и паритет SIMD/scalar/CUDA

  • dt в миллисекундах — везде. Ток — в относительных единицах модели (nA/pA).
  • Никаких делений: храните inv_tau, inv_cm вместо τ и Cm. inv_tau == 0 (τ ≤ 0) — легальная «заморозка» динамики.
  • Клампите аргументы exp до ±50: SIMD-экспонента надёжна до ~±87 (wide возвращает 0 на +88), а expf уходит в inf. Кламп делает сигмоиду одинаковой на CPU-SIMD и CUDA.
  • Маска ≠ арифметика: спайк-маска это NaN (SIMD) или −1.0 (скаляр). Не делайте spike * x — NaN протечёт в состояние. Только cond().then() / blend. Для конвертации — spike_to_float.
  • E_rev — константы: E_CL = −70, E_NA = 0, E_K = −80, E_CA = 0 (мВ).
  • Температура Q10: q10_from_celsius(t), τ_eff = τ/Q10 — конвенция NEURON.
  • Входной ток клампится до ±100 раннером (I_SYN_CLAMP_RANGE) — защита от переполнения и нефизичных частот.
  • Рефрактерность абсолютная: в рефрактерном окне v заморожен, спайк невозможен — никаких back-to-back спайков.
  • Паритет обязателен: новая модель = тесты SIMD/scalar + хвост, стресс NaN/взрыв, и по возможности parity против NEURON.

12Полный рецепт: LIF-AT (GLIF2)

Модель с адаптивным порогом θ — канонический пример из crates/pillars/src/zoo/neurons/lifat.rs

LIF-AT добавляет к LIF динамический порог θ: после спайка порог подрастает на β и экспоненциально затухает — это адаптация частоты спайков (частотная адаптация). 

use pillars_macros::dual_neuron;

#[dual_neuron]                        // ← генерирует ещё и скалярный близнец
pub mod lifat {
    use crate::core::compute::{ComputeNeuron, StepContext};
    use crate::core::lane::SimdLane;
    use pillars_macros::NeuronModel;

    #[derive(NeuronModel)]
    pub struct LIFAtModel {
        #[state] pub v: f32,
        #[state] pub theta: f32,      // адаптивный порог
        #[state] pub refr: f32,

        #[param] pub dt: f32,
        #[param] pub inv_tau_m: f32,
        #[param] pub v_rest: f32,
        #[param] pub v_thresh: f32,
        #[param] pub v_reset: f32,
        #[param] pub inv_tau_theta: f32,  // 1/τ_θ
        #[param] pub beta: f32,           // шаг адаптации порога
        #[param] pub tau_ref: f32,
    }

    impl ComputeNeuron for LIFAtModel {
        type State<S: SimdLane> = LIFAtState<S>;
        type Params<S: SimdLane> = LIFAtParams<S>;

        #[inline(always)]
        fn step<S: SimdLane>(
            state: &mut Self::State<S>,
            params: &Self::Params<S>,
            ctx: &mut StepContext<S>,
        ) {
            let zero = S::zero();
            let is_refr = state.refr.cmp_gt(zero);

            // v — Forward Euler, заморожен в рефрактерности
            let dv = (params.v_rest - state.v + ctx.i_syn)
                * params.inv_tau_m * ctx.dt();
            let v_new = is_refr.cond().then(state.v).else_(state.v + dv);

            // θ — экспоненциальный спад ВСЕГДА (даже в рефрактерности)
            let theta_new = state.theta
                * (-ctx.dt() * params.inv_tau_theta).exp();

            // Спайк: v ≥ v_thresh + θ, только вне рефрактерности
            let spike = is_refr.cond().then(zero)
                .else_(v_new.cmp_ge(params.v_thresh + theta_new));
            ctx.emit_spike(spike);

            state.v = spike.cond().then(params.v_reset).else_(v_new);
            // θ += β через blend — НЕ через `spike * beta` (NaN-утечка!)
            state.theta = spike.cond()
                .then(theta_new + params.beta).else_(theta_new);

            let refr_dec = state.refr - ctx.dt();
            state.refr = spike.cond().then(params.tau_ref)
                .else_(refr_dec).max(zero);
        }
    }
}

Как добавить в проект

  1. Файл crates/pillars/src/zoo/neurons/<имя>.rs с моделью (по образцу выше).
  2. Реэкспорт в zoo/neurons/mod.rs.
  3. Тесты: спайк при токе, тишина без тока, нет back-to-back, стресс NaN при I = ±1000, паритет SIMD/scalar.
  4. Готово — модель доступна и из NeuralPopulation, и из run_neuron, и из Python-биндингов (taas_checkmate.pillars).
Под капотом: dual_neuron #[dual_neuron] — транспилятор поверх #[derive(NeuronModel)], который генерирует ещё и скалярный вариант модели. Нужен для парити-тестов и низкоуровневых ядер, где удобнее скаляр.

13formula-API: свой нейрон из Python

Реалтайм-сборка нейрона из ops на лету — тот же движок api::formula, теперь из Python (PyO3)

В разделе 02 нейрон компилируется в момент сборки проекта. Здесь — тот же движок, но нейрон собирается в рантайме из ops: билдер Neuron с dataflow-операциями, прогон simulate(), компиляция в слот движка и SIMD-популяция. Биндинг: taas_checkmate.formula (+ фасад taas_checkmate.pillars). 

from taas_checkmate.formula import Neuron

# сборка — dataflow: результат одного op передаётся в другой
n = Neuron("DualChannel")
v    = n.state("v", -65.0)            # состояние + дефолт
refr = n.state("refr", 0.0)
n.param("dt", 0.5)                    # dt обязан быть первым
n.param("inv_tau", 0.08)
n.param("v_rest", -65.0)
n.param("v_thresh", -50.0)
n.param("v_reset", -70.0)
n.param("tau_ref", 1.0)

is_refr = n.cmp_gt(refr, n.const_(0.0))          # маска рефрактерности
raw     = n.leak(v, n.I, n.inv_tau, n.v_rest)    # v + (v_rest - v + i)*inv_tau*dt
gated   = n.blend(is_refr, v, raw)               # заморозка в рефрактерности
n.fire_reset(gated, n.v_thresh, n.v_reset, into=v)
n.refr_timer(refr, n.tau_ref, into=refr)

print(n)                                # читаемый список опкодов
tr = n.simulate(steps=500, i_syn=30.0)  # прогон одного нейрона

model = n.compile()                     # слот движка (0..15)
pop = model.population(138_000)         # SIMD-популяция f32x8
pop.set(v_thresh=-48.0)                 # колонки по имени
pop.step(i_in, spikes)                  # zero-copy numpy

Состояния и параметры — атрибуты билдера (n.v, n.inv_tau) и одновременно имена колонок популяции. Ошибки валидации приходят как ValueError.
