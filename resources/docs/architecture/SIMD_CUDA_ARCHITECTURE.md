## 🚀 Ключевые архитектурные решения ядра

```text
  [Python PyO3 Bindings] (Zero-copy NumPy массивы)
            ↓
  [Rust Engine / BrainSimulator]
       ├── [SIMD 8-Lane Memory Layout] (AVX-512 / ARM NEON v8)
       ├── [CSR Sparse Matrix Structure] (4,000,000 синапсов)
       └── [CUDA FFI GPU Accelerators] (NVIDIA CUDA C++ kernels)
```

---

## 1. 8-Lane SIMD Выравнивание памяти (Aligned Memory Layout)

Все векторы нейронных и мышечных состояний строго выравниваются кратно 8 элементам:
- `n.is_multiple_of(8)`
- Память выделяется единым непрерывным блоком, предотвращая промахи кэша L1/L2.
- На процессорах x86_64 Rust компилирует циклы в векторы **AVX-512 / AVX2**, на ARM — в **NEON v8**.

---

## 2. Compressed Sparse Row (CSR) Синаптические матрицы

Для хранения и параллельного прогона 4,000,000 синапсов 153,962 нейронов VNC используется структура CSR:
- `row_ptr`: Индексы начал строк (`u32`).
- `col_indices`: Индексы целевых нейронов (`u32`).
- `values`: Веса синаптических связей (`f32`).
- `nt_types`: Знаки нейротрансмиттеров (GABA = -1.0, ACh = +1.0, GLUT = +1.0).

---

## 3. CUDA C++ GPU Акселераторы

AOT CUDA-ядра находятся в `crates/pillars-cuda/kernels/`, а dual-neuron CUDA source генерируется из моделей `pillars::zoo::neurons` через `#[dual_neuron]`. Исполняемый GPU-драйвер и FFI находятся в `crates/pillars-cuda`.

### Бенчмарки производительности ядра:
- **Размер коннектома**: 153,962 нейрона, 3,990,039 синапсов.
- **Время симуляции 1250 мс биовремени**: всего **1.8 секунды** на CPU.
- **Скорость ядра**: **1 380 шагов в секунду** (0.69× Real-Time на 4 млн синапсов).
