# 🦗 БРЮШНАЯ НЕРВНАЯ ЦЕПОЧКА (VNC) И ФИЗИЧЕСКОЕ ВОПЛОЩЕНИЕ В MUJOCO

Настоящий документ описывает архитектуру физического воплощения коннектома ВНС дрозофилы (*Drosophila melanogaster*) в движке **`taas-checkmate`**.

---

## 🧬 Архитектура биологического VNC коннектома

- **Размер коннектома**: 153,962 нейрона и 3,990,039 синапсов (датасет Franken / Princeton FlyWire).
- **Торакальные ганглии**: T1 (передние ноги), T2 (средние ноги), T3 (задние ноги).
- **Мотонейроны**: 805 мотонейронов, соотнесенных с 136 мышечными каналами 66 суставов лапок.
- **Нисходящие нейроны (DNs)**: 1,315 нейронов (MDN, DNa01, DNa02), передающих GO-команду ходьбы.

```text
  [Descending Neurons (MDN)] ➔ 100% GO Command (nAChR)
         ↓
  [VNC Intrinsic (T1-T3)] ➔ 12,827 нейронов (37.6% ГАМК противофаза)
         ↓
  [Motor Neurons] ➔ 805 мотонейронов лапок (ACh/GLUT)
         ↓
  [Atlasov Ca²⁺ Muscles] ➔ Изометрическая сила 177.85 µN (18.1× веса мухи)
         ↓
  [MuJoCo 3D Physics] ➔ Реальная ходьба и бег по 3D-арене
```

---

## 📊 Запуск и параметры симуляции

Запуск физического бега мухи на базе реального VNC коннектома:
```bash
python3 examples/fly/scripts/vnc_real_atlasov_embodied.py
```
