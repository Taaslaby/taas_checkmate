# Точность против NEURON 9 — сводный отчёт

Все цифры — из реальных прогонов (2026-08-26, `cargo test -p pillars ... --nocapture`).
Эталоны сгенерированы NEURON 9.0 (установлен в `C:\nrn`) скриптами
`resources/validate/neuron_models/gen_*_ref.py`, значения зашиты в Rust-тесты —
CI не требует NEURON.

## Как прогнать

```bash
# Точечные модели
cargo test -p pillars --test hh_vs_neuron --test lif_vs_neuron \
    --test izhikevich_vs_neuron --test adex_vs_neuron --test ks_vs_neuron -- --nocapture

# Кабельные (Hines) + Ca

# Полная Poirazi CA1 (5249 компартментов, ~8 с в release)
```

## Интерпретация

Точность сильно зависит от слоя:

1. **Математически точные ядра** — Markov-гейты и Hines-кабель дают
   суб-милливольт (до **1e-4 мВ**). Расхождение — не ошибка модели, а разница
   интеграторов (pillars: implicit Euler + точная матричная экспонента;
   NEURON: Crank-Nicolson + backward Euler).
2. **AdEx** — 0.03 мВ на гладкой траектории: ожидаемый уровень для forward
   vs backward Euler (обе схемы первого порядка).
3. **voltageClamp 0.47 мВ** — самый большой следовой разброс, ожидаем для
   жёсткого зажима (stiff-система).

## Izhikevich: разбор расхождения

Тест `izhikevich_vs_neuron.rs` помечает RS как 21 спайк против «эталона»
[3,10] (~4.3 Гц из комментария). Независимая проверка канонических уравнений
(0.04v²+5v+140−u+I, dt=0.01–0.5, тот же протокол) показывает:

| Вариант | Канон (тонкий dt) | pillars (dt=0.5) | Эталон в тесте |
|---|---|---|---|
| RS (I=10) | 23 | 21 | [3,10] ❌ |
| FS (I=30) | 462* | 220 | [15,60] ❌ |
| IB (I=10) | 34 | 29 | [3,20] ❌ |
| CH (I=15) | 130* | 96 | [5,30] ❌ |

\* FS/CH: канон с тем же 2 мс абсолютным рефрактерным периодом = 272/141
(см. ниже) — pillars на 0.5 мс шаге даёт 220/96 (малый вклад дискретизации).

**Вывод: модель pillars честно воспроизводит канонические уравнения, а
зашитые в тест диапазоны неверны** — они не выведены ни из NEURON, ни из
канона (вероятно, спутаны с установившейся частотой после адаптации). Тест
проходит только потому, что выход за диапазон понижается до ⚠️ (warn), а не
fail — то есть сверка с NEURON для Izhikevich фактически отсутствовала.

### Почему FS/CH ниже «канона»

Две намеренные семантики pillars, которых нет в исходной модели Ижикевича:

1. **Абсолютный рефрактерный период `tau_ref = 2 мс`** (в оригинале — только
   мягкий сброс v=c). На быстрых паттернах (FS: ISI ≈ 2.2 мс) он съедает почти
   весь межспайковый интервал: 462 → 272 Гц (тонкий dt). На медленных (RS,
   ISI ≈ 45 мс) — пренебрежимо.
2. **u из pre-integration v** (legacy parity с fused-ядром) и заморозка dv в
   рефрактерности — правки, сделанные для стабильности и совпадения с
   легаси-ядром; на частоте сказываются слабее.

### Прямая сверка с NEURON невозможна

В NEURON нет встроенного Ижикевича, а `izh_taas.mod` в репо содержит только
непрерывные ОДУ **без спайк-ресета** (v≥30 → v=c, u+=d) — на пересечении порога
квадратичный член разойдётся. Для полноценной сверки нужно добавить условный
ресет в `BREAKPOINT` мода и сгенерировать эталон скриптом вида
`gen_adex_ref.py`.

## HH: разбор «расхождения» I200

Тест `hh_vs_neuron.rs` показывал pillars 9 против NEURON 3 спайков на I200 и
трактовал это как «CVode против фиксированного шага». Разбор показал: **это
баг конвертации площади, а не физики.**

1. **NEURON Section area — только боковая поверхность цилиндра:**
   π·d·L = 314.16 µm² = 3.1416e-6 cm² (без торцов).
2. Тест же считал площадь закрытого цилиндра 471.24 µm² (с торцами) и
   переводил nA → µA/cm² коэффициентом 212.2 вместо 318.3.
3. В результате pillars гонялся при плотности **1.5× ниже**, чем NEURON:
   на I200 это 42.4 вместо 63.7 µA/cm² — разные режимы (при 63.7 HH входит
   в частичный depolarization block и даёт 3 спайка, при 42.4 — регулярные ~110 Гц).
4. Проверка: NEURON при честной 42.4 µA/cm² даёт **9 спайков — как pillars**;
   pillars при исправленных плотностях 15.9/31.8/63.7 даёт **7/8/3 — как NEURON**.
   Интеграторы (cnexp vs implicit Euler) совпадают на всех конфигах, Δ=0.

### Что сделано (2026-08-26)

✅ `NA_TO_UA` в `hh_vs_neuron.rs` исправлен: 212.2 → 318.3 (истинная площадь
NEURON), обновлены µA/cm² в шапке и убран специальный допуск для I200
(больше не нужен — совпадение точное). Все 6 конфигов: **Δ=0, ✅**.
