🧬 Ключевая мысль: глубина сигнала

# Спайк — это не сигнал, а ИЗМЕНЕНИЕ глубины сигнала. # Вместо: if spike > 0: motor_drive += 1 # дискретно # Теперь: rate = sum(spikes) / window # firing rate depth = rate / target_rate # глубина [0, 1] motor_drive = depth * max_force # непрерывно

Это превращает VNC из дискретного генератора спайков в аналоговый path процессор — сигнал течёт с переменной глубиной, усиливается/ослабляется в каждом нейроне. Ходьба без мозга — это path, а не последовательность спайков.
