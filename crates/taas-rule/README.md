# taas-rule

Интерпретируемые **программные нейроны**: каждый нейрон несёт компактную
программу (до 16 инструкций), которая исполняется виртуальной машиной за
каждый такт симуляции. Программа оперирует аккумулятором, переменными
нейрона и дендрита, химическими концентрациями тела и случайностью.

## Идеи

- **VM правил** — аккумулятор + скорость тендинга (`tendRate`), живущая
  между шагами. ~50 инструкций: переходы (только вперёд), условные
  пропуски, арифметика аккумулятора, тендинг (экспоненциальная релаксация
  `v → цель`), динамика нейрона, обучение, спайковый выход.
- **Геном-программируемые нейроны** — поведение нейрона задаётся не
  формулой в коде, а программой из 16 инструкций, собираемой билдером
  (или генами) и исполняемой VM.
- **Двухконтурные веса** — каждый дендрит несёт краткосрочный `ST`
  (быстро учится) и долгосрочный `LT` (медленно консолидирует `ST → LT`).
  Без подкрепления `ST` тает, `LT` удерживает след — два временны́х
  масштаба памяти.
- **Reward-химия** — обучение гейтируется концентрациями химических
  веществ тела (награда/наказание), адресуемых по id нейрона.

## Ключевые идеи

1. **Тендинг** — дискретный аналог `dv = (x − v)/τ`: состояние тянется к
   цели со скоростью `tendRate`. Всё обучение и адаптация строятся на нём.
2. **Зажатие в [-1, 1]** — все сохраняемые значения зажимаются в единичный
   диапазон, что даёт числовую стабильность в симуляции.
3. **Условные переходы только вперёд** — программы линейны, без циклов.

## Быстрый старт

```rust
use taas_rule::*;
use taas_rule::vm::run_program;

// Программа: порог входа → утечка → покой → постоянство → спайк.
let rule = Rule::from_ops(vec![
    OpCode::NominalThreshold(Operand::Value(0.05)),
    OpCode::LeakageRate(Operand::Value(0.2)),
    OpCode::RestState(Operand::Value(0.0)),
    OpCode::Persistence(Operand::Value(0.4)),
    OpCode::Fire(Operand::Value(0.6)),
    OpCode::Stop,
]);

let mut vars = NeuronVars::default();
let mut fired = false;
for _ in 0..10 {
    vars.input = 1.0; // сильный синаптический вход (каждый такт)
    let out = run_program(&rule, &mut vars, None, &[], 0, 0, None, &mut Rng::new(42));
    fired |= out.fired; // STATE накапливается через Persistence
}
assert!(fired); // 1.0 → состояние накапливается → спайк
```

> ⚠️ `run_program` создаёт свежее состояние VM на каждый вызов — `tendRate`
> не живёт между тактами. Для персистентного тендинга используйте
> [`Neuron::step`](src/neuron.rs) или [`Lobe`](src/lobe.rs), которые хранят
> `RuleVm` внутри.

## Обучаемый пример

`examples/conditioning.rs` — классическое обусловливание: сигнал +
безусловный стимул → условный рефлекс; без награды рефлекс гаснет (ST
стирается), а LT удерживает память.

```bash
cargo run -p taas-rule --example conditioning --release
cargo test -p taas-rule
```
