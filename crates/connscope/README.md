# neoMyelin — «Excel для коннектомики»

> Бинарник/крейт называется `connscope` — **neoMyelin** это продуктовое имя.

Интерактивный исследователь коннектомов на движке **checkmate** (`pillars` +
`pillars-connectome`). Нативный egui/wgpu-стенд: клик по нейрону, ego-граф,
полная симуляция VNC и научные плоттеры — без Jupyter и Python-обвязки.

Работает с реальными данными: **MANC VNC** (102 369 нейронов, 5.2M синапсов),
**FAFB** (139K нейронов), а также GraphML/npz-графы любых коннектомов
(C. elegans, retina, cortex…).

> Справочник по дизайн-системе и внутреннему API — в [DESIGN.md](DESIGN.md).

## Возможности

- **Атлас 2D/3D** — проекции XY/XZ/YZ по реальным voxel-координатам;
  орбитальное облако точек с инерцией камеры и LOD (Potree-стиль: ~15K
  представителей на общем плане вместо 139K).
- **GPU-рендер** (`render::splat`) — биллборд-квады + объёмные сферы на wgpu:
  CPU-сортировка по глубине, диффузное/Phong/rim-освещение, живое свечение.
- **Клик → инспектор** — body_id, тип/подкласс/мишень, класс, нога, сторона,
  нейромедиатор, степени; связи агрегированы по парам (сумма весов + `×N`).
- **Ego-граф** — интерактивная окрестность нейрона (force-directed или по
  реальным координатам), открепляется в перетаскиваемое окно.
- **Симуляция** — LIF / Izhikevich / HH / HAAP на локальном контуре (≤60 узлов)
  или **полный VNC** (вся сеть, поток в 3D): смотри, как вспышки коммутируются
  по мозгу вживую.
- **Библиотека плоттеров** (`app::plotlib`) — растр, частоты, V(t), PSTH (Гц),
  спектр мощности (БПФ + доминирующая частота), тепловая карта время×класс,
  **ISI-гистограмма**, **фазовая гистограмма моторов** (детектор антифазы, r2).
  Каждый плот включается/открепляется в своё окно.
- **Растормаживание** — поиск цепей `тормоз →⊣ тормоз →⊣ нейрон`.
- **Встроенная консоль** (F12) — те же команды, что в CLI, прямо в GUI.
- **NeuroML: окно «Морфология»** — дерево компартментов кабельной клетки
  (ось x = путь от сомы, ветви разнесены по вертикали), клик по компартменту,
  «Запустить и записать трассы» → **V(t) каждого компартмента** + слайдер
  времени с окраской дерева по потенциалу (покой синий → спайк красный).
  Мост: `CableInfo`/`Network::cable_voltage` в `pillars::api::neuroml`.
- **NeuroML: IDE-редактор** — подсветка XML-синтаксиса (теги/атрибуты/
  комментарии), живая валидация на каждый кадр, список ошибок с позициями
  `строка:колонка` (XML-ошибки pillars несут позицию) и подсветкой ошибочных
  строк фоном; «Применить»/«Запустить» идут тем же путём, что и модалка.

## Сборка и запуск

```bash
# из корня воркспейса (crates/..)
cargo run -p connscope --release

# либо собранный бинарник
./target/release/connscope.exe            # Windows
./target/release/connscope                # Linux/macOS

# открыть конкретный файл
./target/release/connscope path/to/manc_viz.bin
```

Первая сборка долгая (eframe + wgpu). По умолчанию грузится
`resources/examples/data/manc_viz.bin`.

## Данные

| Формат | Откуда | Примечание |
|---|---|---|
| `.bin` | `bake_manc_viz.py` | самодостаточный снапшот (позиции, НТ, классы, CSR) |
| `.taas` | `crates/taas-format` | нативный формат checkmate |
| `.graphml` | networkx/igraph | узлы+рёбра, парсится на лету (`io::raw`) |
| `.npz` | FAFB | `from_fafb_npz` |

Формат определяется автоматически по magic-байтам (`MancData::detect`).

## CLI

```text
connscope stats   <file>
connscope search  <file> <запрос>
connscope ego     <file> <idx> [--k 10]
connscope sim     <file> --drive <idx> [--model lif|izh|hh|haap] [--steps 200] [--bias 20] [--pulse 0.6] [--gh 0.3]
connscope fullsim <file> --drive <idx> [--model lif] [--steps 200] [--bias 30] [--pulse 0.6]
connscope disin   <file> <idx> [--top 10]
connscope help
```

## Структура кода

```text
src/
├── main.rs        вход: GUI (App::run) или CLI (cli::run) + тесты
├── app/           ядро GUI (egui): camera, picking, ego, canvas,
│                  inspector, sim_ui, console_ui, plots, plotlib, …
│   neuroml/       режим NeuroML: модалка (ui.rs), окно «Морфология» (cable.rs),
│                  IDE-редактор с подсветкой и валидацией (editor.rs)
├── render/        atlas (2D/3D-запечка) · lod (уровни детализации) ·
│                  splat (GPU-облако точек)
├── io/            data (MancData + .bin/.taas) · raw (GraphML/npz/csv)
├── core/          nt (нейромедиаторы/классы) · color (режимы окраски)
├── sim.rs         симуляция (LIF/Izh/HH/HAAP, полный прогон, живой поток)
├── cli.rs         CLI-комбайн
└── console.rs     состояние встроенной консоли
```

## Клавиши / управление

- **F12** — встроенная консоль.
- 2D: колесо = зум, drag = пан, клик = выбрать нейрон.
- 3D: drag = орбита (с инерцией), колесо = зум, клик = выбрать.
- Правый клик / выделение — подсветка выбранного нейрона и его ego-графа.
