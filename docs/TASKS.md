## B. Конструктор нейрона (Formula в приложение) — главный прикол
- [x] **B1 ⭐** Порт `viz_neuron_builder` в connscope как dock-поверхность «Конструктор» (`Surface::Builder`): нодовый граф → `OpNode`-программа → живая симуляция (SIMD).
- [ ] **B2 ⭐** Dual-lane для Formula: `run_program` над дуальными числами → градиенты из нодового графа (E-prop/Hebbian).
- [ ] **B3 ⭐** CUDA-кодген для OpNode-программ: сериализация в C++ строку + NVRTC (как `#[dual_neuron]` для зоопарка). Симметрия: compile-time DSL уже умеет SIMD+dual+CUDA, рантайм-DSL — только SIMD.
- [ ] **B4** Валидатор программ Formula + автораспределение регистров (сейчас ручные `t0..t50` — тихий мусор при неинициализированных темах).
- [ ] **B5** Фарма в конструкторе: препарат масштабирует conductance-оп в собранной программе.
