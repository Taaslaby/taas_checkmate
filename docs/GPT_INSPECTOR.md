# 🧬 GPT Inspector — Path Scanner для трансформеров

**Сканер путей через ReLU активации.** Инструмент, который применяет коннектомный подход (Connectome-FST, Chaos/Pattern contrast) к анализу тензорных нейросетей.

## Проблема

Трансформеры — это **чёрный ящик**. Тензоры — это математический суп, который невозможно графировать:

```
GPT-2 forward pass: 
  x₀ → Attn₁ → MLP₁(ReLU) → x₁ → Attn₂ → MLP₂(ReLU) → ... → logits
  └─────────────────────────────────────────────────────────────┘
                       85M параметров, всё вперемешку
```

Ты не можешь сказать:
- От токена "Paris" до выхода — какой путь?
- Какие MLP нейроны отвечают за грамматику, а какие за семантику?
- Где происходит разделение между "столица" и "страна"?

## Решение: ReLU как спайк → суп становится графом

**Ключевое открытие:** ReLU(x) = max(0, x). Когда x > 0, нейрон активен. Когда x = 0, молчит.

**Это наш порог детекции спайков.** Только вместо Kuramoto phase > threshold у нас ReLU > 0.

```
Наш коннектом:           phase > 2.5 → spike = 1
GPT-2 MLP:               ReLU(x) > 0  → neuron = active

Результат: 80%+ MLP нейронов = 0 (тишина)
           ~20% MLP нейронов > 0 (спайки)
           → Разреженный граф!
```

**Тензор 12×768×3072 невозможно нарисовать.**
**А 12×515 активных нейронов — можно. Это граф.**

## Connectome-FST аналогия

| | Наш коннектом (CPE) | Трансформер (GPT-2) |
|---|---|---|
| **Нейроны** | 800 Kuramoto осцилляторов | 12×3072 = 36,864 MLP нейронов |
| **Связи** | CSR матрица (20K синапсов) | W_in, W_out (85M параметров) |
| **Спайки** | phase > threshold → spike | ReLU(x) > 0 → active |
| **Группы** | sensory, mn, dn | embedding, layer_N, logits |
| **Обучение** | STDP + dopamine δ | Backpropagation |
| **Анализ** | Chaos/Pattern контраст | Prompt contrast |
| **δ** | R_pat − R_cha | H(prompt_A) − H(prompt_B) |

## GPT Inspector: реализация

```
gpt_inspector.py — сканер путей через HuggingFace transformers

1. Загружает GPT-2 (или любую модель) через transformers
2. Регистрирует forward hooks на MLP.act (gelu/ReLU) каждого слоя
3. Прогоняет два промпта, кэширует активации всех слоёв
4. Строит контраст: XOR бинарных масок активации
5. Трассирует пути: top-k активных нейронов на последнем токене
6. Считает метрики:
   - Sparsity: % активных нейронов на слой
   - Contrast: Only A, Only B, Both, Jaccard
   - Path Coherence: Jaccard между соседними слоями
   - Entropy: Shannon H = −Σ p·log₂(p), нормированная на log₂(d_mlp)
   - Chaos/Pattern δ = Hnorm(B) − Hnorm(A)
```

### Пример запуска

```bash
python3 examples/python/gpt_inspector.py \
    --prompt "Paris is the capital of" \
    --contrast "Moscow is the capital of"
```

### Результат (GPT-2 small)

```
📊 SPARSITY: 16.78% MLP нейронов активны
🔬 CONTRAST:  Jaccard = 1.000 на всех слоях
🎲 ENTROPY:   H = 8.53 (Hnorm = 0.736)
📈 δ = 0.000 — идентичные паттерны
```

**Интерпретация:** MLP нейроны GPT-2 обрабатывают **синтаксическую структуру**, а не семантику. "Paris is the capital of" и "Moscow is the capital of" — одинаковая грамматика → одинаковые MLP активации. Семантическое различие живёт в эмбеддингах и attention.

## Пути развития

### 1. Контраст: осмысленный vs бессмысленный

```bash
python3 gpt_inspector.py \
    --prompt "Paris is the capital of" \
    --contrast "xqy zrk mplw qx"
# → Jaccard < 0.5, большой δ
# → Покажет КАКИЕ нейроны отвечают за синтаксис
```

### 2. Attention tracing

Добавить tracing attention heads: куда "смотрит" модель для каждого токена. Attention — это динамические синапсы. В коннектомной аналогии:

```
Наш CSR:               w_ij = вес синапса (константа)
Transformer attention: a_ij = softmax(QK^T) (динамический вес)
```

### 3. Path visualisation

Построить граф активных нейронов через networkx:

```
embed[42] → layer_3.mlp[1731] → layer_7.mlp[44] → logit["Paris"]
   0.73         2.1 (ReLU)        0.8 (ReLU)        0.54
```

### 4. FST полный цикл

Загрузить GPT-2 как `.taas`:
- Нейроны: MLP ReLU > 0 = активные вершины
- Связи: w_in · w_out между слоями
- Группы: embedding = sensory, logits = motor
- Запустить CPE на этом графе

## Философия

Тензоры — это математика, которую невозможно графировать (как сказал пользователь). Но **разреживание через ReLU делает их графируемыми.** 

80%+ нейронов молчат на любой вход. Это не шум — это **структура.** Только 20% активных нейронов несут информацию. И эти 20% образуют **путь** — направленный ациклический граф от входа до выхода.

**То, что мы построили:**

1. Анализируем не весну матрицу (85M чисел), а **путь через активные нейроны** (сотни на токен)
2. Применяем коннектомные методы (coherence, contrast, entropy) к трансформеру
3. Делаем чёрный ящик **прозрачным** — через те же инструменты, что и для мозга мухи

Это мост между:
- **ConnectomeGPT** (дизассемблер мозгов, sparse, Kuramoto, STDP)
- **Transformer interpretability** (ReLU пути, attention, mechanistic)
- **Тензорные нейросети** (GPT-2, LLM, dense)

**Поле для следующего шага:** собрать всё в один инструмент — загрузить любую нейросеть, построить её CSR-граф, пройтись по путям, найти точки ветвления, применить CPE обучение.
