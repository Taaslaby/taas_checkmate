# Эксперимент: «Из генома — в гамма-ритм»

Флагманская демонстрация **обоих движков** в одном конвейере: сеть из 200 нейронов
выращивается из правил развития (диффузия + градиенты + контактное замыкание),
а затем её динамика считается на SIMD-движке pillars.

```text
prometheus-grow (развитие)                  pillars (динамика)
──────────────────────────────────────────────────────────────
клетки секретируют морфоген "A"    ──►    ConnectomeData (CSR)
ростовые конусы карабкаются по градиенту  BrainRunner, SIMD LIF-α
аксоны встречают сому → синапсы            (модель Shiu et al. 2024)
└─► локально-кластерный E/I граф           └─► пространственно
                                             когерентные ансамбли
```

## Запуск

```bash
cargo run -p pillars-connectome --example genome_to_gamma --release
```

## Идея

Вопрос: достаточно ли **только правил развития** (без рукописных весов и таблиц
геометрии), чтобы построить сеть с нетривиальной динамикой? Или любой случайный
граф с той же степенью даст то же самое?

**Контроль:** берём выращенный коннектом и перемешиваем мишени синапсов
(степенная последовательность сохранена, геометрия уничтожена). Те же нейроны,
то же число синапсов, тот же состав E/I — исчез только порядок развития.

## Результаты (i5-12400F, один прогон)

| шаг | grow (выращенный) | shuffled (контроль) |
|---|---|---|
| синапсы | 1969 (200 нейронов: 160 E / 40 I) | те же степени |
| кластеризация C | **0.616** | 0.099 (в 6× ниже) |
| средняя частота | 32.5 Гц | 31.8 Гц |
| доминантный ритм | **25 Гц**, пик 99× над фоном | 25 Гц, пик 74× |

**Пространственная синхронизация (корреляция спайков vs. расстояние между сомами, бины 50 мс):**

| расстояние | grow | shuffled | ratio |
|---|---|---|---|
| 13 µm | **0.060** | 0.012 | **4.9×** |
| 39 µm | 0.006 | 0.011 | 0.5 |
| 64 µm | 0.004 | 0.010 | 0.4 |
| 90 µm | 0.004 | 0.012 | 0.3 |
| 116 µm | 0.003 | 0.014 | 0.2 |

## Вывод

1. **Правила развития сами создают структуру.** Кластеризация 0.62 против 0.10 у
   контроля при одинаковых степенях — это отпечаток геометрии: аксоны
   ограниченной длины (30 µm) замыкают соседей, а не центр.
2. **Структура создаёт функцию.** Соседние нейроны (13 µm) корофируют в **4.9×**
   сильнее контроля, и корреляция спадает с расстоянием (градиент 0.06 против
   плоского ~0 у контроля). Развитие строит пространственно-когерентные
   ансамбли — геометрия важна.
3. **Популяция ритмична.** 25 Гц с пиком спектра 99× над фоном — бета/гамма
   ритм без каких-либо рукописных параметров ритма.
4. **Оба движка быстры.** Рост 200 нейронов (300 шагов с диффузией) — 0.6 с;
   динамика 200 нейронов × 50 000 шагов (25 с симуляции) — **0.03 с**
   (320+ млн клетко-шагов/с).

## Как устроено

- **Развитие:** 160 возбуждающих + 40 тормозных клеток в шаре радиусом 65 µm,
  каждая секретирует общий морфоген "A"; аксоны E-клеток — 2, I-клеток — 1,
  растут по градиенту с шумом и **останавливаются после 30 µm** (короткодействующие
  аксоны → локальность). Синапсы образуются при контакте конуса с сомой в радиусе
  13 µm. Вес синапса — логнормальное распределение (как в реальном VNC),
  знак — от типа клетки (GABA → тормозной).
- **Мост:** GrownGraph → CSR (ConnectomeData), нейротрансмиттеры E/I.
- **Динамика:** LIF-α (v_th = -45 мВ, τ_mem = 20 мс, τ_syn = 3 мс), тонический
  драйв 0.2 мВ/шаг; веса E = 0.15×, I = 0.8× (баланс E/I ≈ 1.0).
- **Контроль:** конфигурационная модель — для каждого источника d_i случайных
  различных мишеней (та же степенная последовательность).

## Крутилки

В начале файла: `N_E`, `N_I`, `SYNAPSE_DIST`, `DRIVE`, `W_E_GAIN`, `W_I_GAIN`,
`tau_syn`. Наблюдаемые режимы:

| драйв | ритм | пространственный контраст |
|---|---|---|
| 0.20 мВ/шаг | 25 Гц, пик 99× | **сильный (4.9×)** ← по умолчанию |
| 0.23 мВ/шаг | 37 Гц (гамма) | слабый (1.3×) |

Это честный компромисс: сильный драйв глобально синхронизирует сеть и размывает
локальную структуру. Выбирайте режим под задачу.
